# Vision-based Assembly Target Pose Estimation and Adaptation for Robotic Assembly in Modular Integrated Construction

## Dataset

**Download (Baidu Netdisk):** [Dataset](https://pan.baidu.com/s/1VmMrQzGJpBLb8-6R132YYA?pwd=irib)　提取码: `irib`

We release construction-site RGB-D datasets of **convex** and **concave** assembly targets. Convex targets are protruding rectangular connectors; concave targets are recessed rectangular grooves. Data were captured with a ZED 2i (1280×720). RGB / depth are paired by filename (~300 train + ~100 test per dataset).
